# Sources and licences

FHIR R5 5.0.0 official downloads, unmodified definitions and GraphQL files:
https://hl7.org/fhir/R5/downloads.html
https://hl7.org/fhir/R5/definitions.json.zip
https://hl7.org/fhir/R5/fhir.schema.json.zip
https://hl7.org/fhir/R5/fhir.schema.graphql.zip
FHIR attribution: HL7 International, FHIR R5. See https://hl7.org/fhir/R5/license.html for upstream terms. Original notices remain in the files.

openEHR official development JSON Schema repository and REST specification repository:
https://github.com/openEHR/specifications-ITS-JSON
https://github.com/openEHR/specifications-ITS-REST
Upstream licences are retained under schemas/openehr/LICENSE and schemas/openehr/rest/LICENSE. JSON Schema catalog/GraphQL projections are AriannA-generated derivatives; official originals remain unchanged. YAML-to-JSON OpenAPI copies preserve their upstream content. The source manifests identify the downloaded snapshots; they do not turn development schemas into stable specifications.

GraphQL and YAML npm packages were used only for build/test analysis and are not runtime dependencies. dicom-parser was used only as an independent test reference and is not bundled.
