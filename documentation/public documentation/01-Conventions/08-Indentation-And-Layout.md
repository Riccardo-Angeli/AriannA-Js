# Indentation and Layout

- four spaces, never tabs;
- opening braces on their own line;
- one semantic operation per visual block;
- multiline calls and arrays are vertical;
- long ternaries are decomposed;
- blank lines separate validation, work and return;
- public methods are not compressed into one line;
- small coherent object blocks may align colons;
- separator banners never replace real namespace/class organization.
