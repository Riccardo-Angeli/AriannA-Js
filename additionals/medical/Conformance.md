# Scope: definitions, not clinical conformance

The earlier absence note is superseded. Fhir.ts and OpenEHR.ts now implement schema-driven document construction and mapping, with official JSON definitions and official/generated GraphQL definition files as documented in documentation/Medical.md.

Clinical validation, terminology inference, server persistence, ADL/OPT compilation, AQL execution and SSN conformance are intentionally outside the clarified scope. Source data, version manifests and licences are included under schemas/.
